# Fence provisioned tenant-key Catalog state with Format Epoch 2

Catalog Format Epoch 2 is the boundary for provisioned tenant-key envelopes and plural tenant registry state. A current binary reads Epochs 1 and 2; a released Epoch-1 reader rejects an authenticated Epoch-2 commit marker as `UnsupportedFormat` before loading the Catalog snapshot or admitting data. Epoch-1 governance objects and their authenticated legacy tenant-envelope route remain readable without replacement. The concrete V1-to-V2 transformation copies the complete immutable object set into Epoch-2 object artifacts and publishes one redacted audited successor while runtime data admission is drained. A fault before the marker leaves V1 current. There is no V2-to-V1 path. The later Upgrade and Migration operation orchestrates preflight, snapshots, and release workflow; this decision defines only the durable representation boundary required for tenant provisioning.
