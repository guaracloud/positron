# Bind every wrapped key to a verified envelope context

Every wrapped key uses a deterministic versioned Protobuf Wrapped Key Payload containing the key bytes, instance identity, key kind, immutable key ID and epoch, tenant or system scope, and SHA-256 Envelope Context digest. Local Root and Tenant KEKs wrap these payloads using AES-256-KWP; external providers use native wrap or encrypt operations and provider-native context where available. The plaintext Key Envelope contains only format and provider routing fields, child-key identity, context digest, and opaque ciphertext and remains untrusted until it exactly matches the unwrapped payload. Positron always verifies embedded context even when the provider authenticates context independently. Wrong scope, substitution, or context mismatch fails closed as `KEY_ENVELOPE_CONTEXT_MISMATCH`, marks storage unhealthy, and produces a Governance Audit Record. Temporary plaintext payloads and unwrapped keys are zeroized immediately.
