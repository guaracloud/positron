# Make encryption mandatory and bootstrap a local key

Every Release 1 instance encrypts all Positron-managed persistent data at rest, with no production plaintext mode or opt-out. On first start of a fresh empty instance, when the operator supplied neither a Key Provider nor key material, Positron bootstraps a cryptographically random local Root KEK using an exclusive atomic write and owner-only permissions and never prints the key. Every subsequent startup with that automatically managed key emits an explicit warning about its custody and recovery limitations and recommends an external provider; the bootstrap is recorded once the Governance Audit Store is available. Automatic generation is never used for recovery or provider fallback: an initialized instance with a missing or invalid key, or an unavailable configured external provider, fails closed without generating replacement material.
