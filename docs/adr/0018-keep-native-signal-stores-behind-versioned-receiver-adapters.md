# Keep native signal stores behind versioned receiver adapters

Positron remains a standalone backend whose versioned receiver adapters decode external protocols into vendor-neutral native signal models; ingest compatibility never implies query, dashboard, storage-format, or backend emulation. Release 1 accepts OTLP logs and traces over gRPC and HTTP plus Loki Push and Loki's OTLP log path, while follow-on Metric and Profile Stores add OTLP Metrics, Prometheus Remote Write, versioned OTLP Profiles, and Pyroscope Push or pprof adapters. Every named Alloy, Tempo, Loki, Pyroscope, Beyla, E-Navigator, or OpenTelemetry claim requires a pinned real conformance target and preserved signal semantics. An adapter must reject data rather than weaken tenancy, durability, typing, bounded-resource, storage, or query invariants; changing an invariant requires a superseding ADR.
