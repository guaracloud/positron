# Ship five external key-provider families in Release 1

Release 1 ships a protected local key-file provider plus AWS KMS, Google Cloud KMS, Azure Key Vault and Managed HSM, HashiCorp Vault Transit, OpenBao Transit, and KMIP 2.1 providers. Every provider must pass the same wrap, unwrap, verification, outage, rotation, and wrong-key conformance suite; Vault and OpenBao remain separate conformance targets even when they share protocol code. Positron persists only immutable Provider Key URIs, opaque provider references, and wrapped key material, uses provider-native workload identity or externally supplied credentials, and never copies provider credentials into its data or backups. Generic executable and arbitrary-webhook providers are excluded from Release 1 because they cannot meet the same credential-containment and protocol-conformance contract.
