# Encrypt independent frames with AES-256-GCM

Release 1 encrypts persistent content as independently addressable AES-256-GCM frames. Each segment has a random 256-bit DEK, and every frame under that DEK has an immutable sequence number from which Positron derives a unique 96-bit nonce. Store Blocks, indexes, statistics, and segment metadata remain separate frames for random access; associated data binds tenant, Signal Store, Virtual Shard, segment, payload kind, sequence number, and storage-format version. A ciphertext checksum permits keyless corruption detection while the AEAD tag is authoritative for authenticity. Only the bootstrap fields required to identify the format and recover the wrapped DEK remain plaintext. Catalog, manifest, governance-audit, and backup metadata use the same construction with independent system-object DEKs. The format carries an algorithm identifier for future migration, but Release 1 exposes no alternate cipher. Crash recovery truncates and seals an interrupted encrypted active segment and always creates a new segment and DEK before accepting more writes, preventing nonce reuse.
