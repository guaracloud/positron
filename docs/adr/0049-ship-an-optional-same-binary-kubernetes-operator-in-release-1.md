# Ship a deployment-optional same-binary Kubernetes operator in Release 1

Release 1 ships a deployment-optional Rust Positron Operator inside the standard OCI image: `positron operator` runs the Kubernetes controller and `positron serve` runs the database. The initial CRDs are `PositronCluster`, `PositronBackup`, and `PositronScheduledBackup`. The operator reconciles Kubernetes-native workload, service, storage, configuration, credential, network, disruption, TLS, Key Provider, backup, restore, fencing, hibernation, upgrade, and status resources while the database remains independently runnable without Kubernetes. `PositronCluster.spec.instances` is fixed to `1` and higher values are rejected until native replication and failover exist. Deletion retains PVCs, backups, and external keys by default. Future clustered releases extend the same resource model with replication, leader placement, switchover, failover, and Virtual Shard movement. The operator uses Positron's public administrative APIs and never owns storage, durability, query, or signal semantics.
