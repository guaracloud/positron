# Cache unwrapped KEKs with bounded memory leases

External Key Providers are never called on the per-frame ingest or query path. Unwrapped system and Tenant KEKs exist only in a bounded, zeroizing process-memory cache, with memory locking where supported. A Key Cache Lease defaults to 15 minutes, is configurable down to zero, and has a hard maximum of one hour. During a provider outage, operations with valid cached KEKs may continue until lease expiry; uncached or expired keys return retryable `KEY_PROVIDER_UNAVAILABLE` results for affected tenants without provider or plaintext fallback. Provider failure marks health degraded, expiry of the system KEK makes the instance not-ready, and startup or restore always requires live provider verification. Rotation, revocation, credential reload, and administrative purge through Positron evict affected entries immediately; unannounced provider-side changes take effect no later than lease expiry. Plaintext key caches are never persisted.
