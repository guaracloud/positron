# Use envelope encryption with local and external key providers

The Storage Kernel uses a provider-owned root KEK to wrap system and tenant KEKs, while each tenant KEK wraps randomly generated per-segment DEKs. Root KEKs and provider credentials are never stored in Positron data or backup repositories; only provider and key references plus wrapped keys are persisted. Release 1 ships a protected local key-file provider and external key providers behind one Rust interface, and startup or restore fails closed when a required provider or key cannot be verified. Root rotation rewraps system and tenant KEKs, tenant rotation rewraps segment DEKs, and neither rotation rewrites telemetry solely to change its wrapping key. Release 1 includes CLI tooling for initialization, provider health, verification, rotation, and recovery checks; the required provider set is fixed separately.
