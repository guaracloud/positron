# Require independent key recovery before backup

Root KEKs, Key Provider credentials, and Recovery Bundles are never included in ordinary Backup Snapshots. An instance using an automatically bootstrapped local Root KEK cannot create a backup until `positron keys recovery create` has produced a separately stored, authenticated encrypted Recovery Bundle for operator-supplied recipients and `positron keys recovery verify` has proved that it matches the instance fingerprint without changing the active key. The startup warning persists until that verification succeeds. For external KMS or HSM providers, Positron verifies current provider access and records immutable provider and key identities while relying on provider-native replication, backup, or disaster-recovery controls for the non-exportable root key. A snapshot cannot be reported as a successful backup when its required key recovery path is unverified.
