# Make operator backups visible, application-verified, and restore-only

`PositronBackup` is an immutable one-shot request whose operator invokes the running database through its authenticated administration API without mounting the live PVC elsewhere. Status records timing, manifest digest, byte counts, incremental reuse, key readiness, and verification and reaches `Completed` only after application consistency, signatures, Repository Key Registry state, and key recovery pass. `PositronScheduledBackup` creates a visible backup resource for every execution with explicit timezone, deadline, retention, and default `Forbid` concurrency. Kubernetes object deletion retains repository data unless an audited deletion policy explicitly says otherwise, and credentials use workload identity or Secret references without leaking into status or Events. Restore bootstraps a new `PositronCluster` and fresh PVC, applies Purge Tombstones before readiness, and rejects in-place, merge, and non-empty targets. CSI VolumeSnapshots are not equivalent backups in Release 1. Reconciliation resumes after interruption without duplicating a completed backup.
