# Freeze Release 1 through an evidence-backed Qualification Matrix

Release 1 is frozen to the standalone Log and Trace Signal Stores, named OTLP and Loki receivers, native query and correlation surfaces, Grafana data source, SDK Release Set, and every accepted security, governance, lifecycle, storage, backup, operator, distribution, diagnostic, compatibility, provider, and supply-chain contract. Required integration and distribution artifacts remain release-blocking even when they are optional to deploy and never become database runtime dependencies. Metrics, profiles, replication and HA, identity federation and custom RBAC, FIPS claims, PITR and selective restore, legal hold and arbitrary deletion, alternate primary storage, vendor query languages, and native Windows or FreeBSD remain follow-on. Every required capability-and-target Qualification Cell advances independently through `Specified`, `Implemented`, and `Qualified` and maps to an ADR, owner, executable gate, and immutable evidence; dynamic selectors must first resolve into an exact versioned Qualification Target Registry. Correctness, durability, encryption, isolation, no impersonation, governance atomicity, purge, integrity, restore, and artifact authenticity are non-waivable. Performance objectives and inputs are preregistered before candidate tuning, soak proves bounded resources, and passing results cannot hide failing providers, architectures, registries, or platforms. Scope change requires a superseding ADR with cost, schedule, compatibility, and evidence impact. Seven vertical milestones build contract generation, kernel proof, logs, traces, governance, operational surfaces, then full qualification, and the Release Manifest cannot complete until every required cell for the exact artifact set qualifies.
