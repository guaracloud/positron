# Preserve dynamic values behind bounded schema and index budgets

Release 1 preserves the supported OTLP value model, separate resource, instrumentation-scope, and record namespaces, cross-record typed variants, and ordered Attribute Occurrence Sets without implicit coercion or last-write-wins behavior. One Value Limit Profile bounds transport expansion, request and record size, bodies and values, attribute counts, keys, nesting, arrays, and key/value lists under hard system maxima and optional lower tenant limits. Exceeding a limit rejects explicitly; only a configured pre-persistence Ingest Policy may transform content. Each Tenant Schema Catalog has bounded entries, memory, storage, and index budget. Valid paths beyond those budgets remain fully typed and explicitly queryable in Schema Overflow without growing catalog, planner, statistics, or automatic-index state. Discovery surfaces bounded summaries and overflow evidence, while Attribute Promotion spends a reversible per-tenant index budget without changing logical results. CLI, administration, operational metrics, and adversarial receiver tests prove limits, duplicate and type semantics, compression bounds, and policy ordering.
